Progress Presentation II

March 2026 Completed
Submitted

Progress Presentation II showcased advanced model development, optimised performance metrics, integrated system components, and completed implementation with full evaluation results across all four components.

C1 LogReg+TF-IDF (97.5% acc) and C3 XGBoost+Bootstrap (ROC-AUC 0.9951) optimised and deployed
DenseNet-121 model achieving target AUROC on CheXpert validation set with Grad-CAM integration
Full recommendation engine with confidence scoring and 15-label diet plan generation
TinyLlama-1.1B QLoRA fine-tuned chatbot with PHQ-9/GAD-7 assessment fully operational
Integrated CardioSense web application with all 4 components functional
Complete system integration with Firebase backend and PDF report generation
User acceptance testing and system evaluation completed
