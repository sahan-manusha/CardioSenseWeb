Component 1
Daniru Malalagama
IT22126856
Cardiovascular Risk Prediction
Logistic Regression TF-IDF SHAP StandardScaler Scikit-learn Python
Develops a hybrid NLP-ML pipeline combining TF-IDF text vectorisation of symptom descriptions with structured clinical features (age, BP, cholesterol, lifestyle) using Logistic Regression. Achieves 97.5% accuracy and 98.34% ROC-AUC on the cardiovascular risk dataset (13 features).

Component 2
Sahan Athukorala
IT22296146
Chest X-Ray Analysis
DenseNet-121 Grad-CAM PyTorch 14-label Multi-label CheXpert opencv-python
Fine-tunes DenseNet-121 (PyTorch) on 14-label chest X-ray pathology classification including cardiomegaly, pleural effusion, and atelectasis. Integrates Grad-CAM heatmaps for visual explainability and uses class-balanced training to address dataset imbalance on the CheXpert dataset.
Deep Learning (DenseNet-121)94%

Component 3
Radeesa Randini
IT22638854
Personalised Recommendations
XGBoost (calibrated) OneVsRest LR Bootstrap Ensemble 15 Labels Kaggle 70K Counterfactual AI
Trains a calibrated XGBoost risk model (ROC-AUC: 0.7999) and a OneVsRest Logistic Regression recommender (mean ROC-AUC: 0.9951) on 68,583 cardiovascular records. Outputs 15 ranked lifestyle recommendations (diet, activity, smoking, sleep, clinical follow-up) with bootstrap confidence scoring and counterfactual risk-reduction ranking.
Risk Model (ROC-AUC: 0.7999)80%
Recommender (Mean ROC-AUC: 0.9951)99%

Component 4
Shehan Kuruneru
IT22230706
Mental Health Monitoring Chatbot
TinyLlama-1.1B QLoRA (4-bit) LoRA rank=16 PHQ-9 / GAD-7 MentalChat16K Empathetic Dialogues
Fine-tunes TinyLlama-1.1B (LlamaForCausalLM) using QLoRA (4-bit quantisation, rank=16) on 38,249 mental health conversations from MentalChat16K, Empathetic Dialogues, MedQuAD (cardiac-filtered), and CounselChat. The trained model provides empathetic cardiac patient support, administers PHQ-9/GAD-7 assessments, and generates risk-tiered clinical alerts.
