Frequently Asked Questions
Is the CardioSense system available for clinical use?
CardioSense is currently a research prototype developed as part of an undergraduate research project at SLIIT. It is not yet approved or deployed for clinical use. All results are for research and demonstration purposes only.
Can I use the research documents for my own study?
Yes — the research reports are shared for academic reference. Please cite each document appropriately using the citation format provided on the Documents page. Contact the team for clarification on usage rights.
How can I collaborate with the CardioSense team?
We welcome academic collaboration, feedback from clinicians, and dataset sharing for validation purposes. Use the contact form to reach us with collaboration proposals, and we will respond through SLIIT channels.
Which datasets does CardioSense use?
Component 1 uses the UCI Heart Disease Dataset. Component 2 uses the CheXpert chest X-ray dataset. Components 3 and 4 use proprietary compiled datasets with appropriate ethical clearance.
Is the source code publicly available?
The project source code is a private academic submission. A code release may be considered post-assessment completion. Contact the supervisor or team for academic access requests.
