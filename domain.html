Research Gap

What's Missing in Current Solutions

Five critical gaps identified across cardiovascular health AI systems that CardioSense aims to address

1

Over-reliance on Structured Data

Existing CVD prediction models rely exclusively on structured clinical metrics (BP, cholesterol, age), ignoring the rich diagnostic information embedded in patients' free-text symptom descriptions. No hybrid NLP+ML framework combines both data types effectively.

2

CXR Analysis Without Clinical Explainability

Most chest X-ray AI systems use CNNs (DenseNet, ResNet) without visual explainability — clinicians cannot verify why a pathology was flagged. No production system combines multi-label DenseNet-121 classification with Grad-CAM heatmaps for transparent, per-pathology visual explanations.

3

Generic, Non-Explainable Recommendations

Digital health tools provide generic lifestyle advice without personalisation to individual risk profiles. No system aligns recommendations with AHA/WHO guidelines while providing transparent IF-THEN reasoning and measurable confidence levels.

4

Absence of Continuous Mental Health Monitoring

Mental health assessment for CVD patients occurs only during infrequent clinical visits. No continuous, multi-modal AI system monitors patient-generated text, voice, and behavioral patterns between appointments with real-time explainable risk alerts.

5

Fragmented, Siloed Cardiovascular AI Tools

Current cardiovascular AI solutions address individual problems in isolation. There is no unified, end-to-end platform integrating risk prediction, imaging analysis, personalised recommendations, and mental health monitoring into a single clinical-grade system.

Research Problem

Problem Statements

🔬

Component 1 — Risk Prediction

How can a hybrid NLP-ML framework effectively integrate free-text symptom descriptions with structured clinical metrics to achieve accurate, interpretable, and low-resource-compatible cardiovascular disease risk prediction?

🩻

Component 2 — CXR Analysis

How can a fine-tuned DenseNet-121 model with Grad-CAM visual explainability achieve accurate multi-label cardiac pathology detection from chest X-rays while providing clinically interpretable heatmap overlays for deployment in resource-constrained healthcare settings?

💡

Component 3 — Recommendations

How can an AI-powered system translate individual cardiovascular risk scores into customised, evidence-based lifestyle plans while providing transparent, explainable recommendations with measurable confidence levels aligned to global clinical guidelines?

🧠

Component 4 — Mental Health

How can a domain-adapted large language model (TinyLlama-1.1B fine-tuned via QLoRA on 38K mental health conversations) provide empathetic, clinically structured mental health support for cardiovascular patients — including PHQ-9/GAD-7 assessment and safety-tiered risk alerts?

Research Objectives

What We Aim to Achieve

Component 1 — CVD Risk Prediction

Main Objective: Develop an AI-powered symptom analysis and CVD risk prediction framework combining structured and unstructured health data for accessible, interpretable risk assessment.

  • Build a hybrid NLP-ML pipeline combining TF-IDF vectorisation of free-text symptom descriptions with 13 structured clinical features (age, BP, cholesterol, BMI, lifestyle)
  • Train a Logistic Regression classifier achieving 97.5% accuracy and 98.34% ROC-AUC on the cardiovascular risk dataset
  • Integrate SHAP explainability to provide transparent patient-level risk factor attribution for each prediction
  • Package the pipeline (StandardScaler + TF-IDF + LogReg) as a deployable .pkl model via scikit-learn
  • Develop an early warning alert system for high-risk patients integrated into the web application
  • Ensure prediction latency under 3 seconds for real-time clinical use

Component 2 — Cardiovascular Image Analysis

Main Objective: Develop an AI-based system using CNNs and Vision Transformers for real-time, accurate cardiovascular disease detection from chest X-rays with Explainable AI for clinical transparency.

  • Fine-tune DenseNet-121 (PyTorch) for 14-label multi-label chest X-ray pathology classification on the CheXpert dataset
  • Implement class-balanced training to address label imbalance across conditions including cardiomegaly and pleural effusion
  • Integrate Grad-CAM visual explanations to generate heatmap overlays indicating regions driving each prediction
  • Achieve multi-label inference with per-class probability output and top-finding identification
  • Deploy the model as a PyTorch .pth checkpoint loadable via torchvision for production inference
  • Produce PDF reports with annotated X-ray heatmaps and per-pathology confidence scores

Component 3 — Personalised Recommendations

Main Objective: Build an AI-powered framework that translates CVD risk scores into personalised lifestyle plans with transparent, clinically validated recommendations and confidence levels.

  • Train a calibrated XGBoost classifier (CalibratedClassifierCV, isotonic) on 68,583 cardiovascular records achieving ROC-AUC 0.7999 and PR-AUC 0.7737
  • Build a OneVsRest Logistic Regression recommender for 15 lifestyle labels (diet, activity, smoking, alcohol, sleep, clinical follow-up) achieving mean ROC-AUC 0.9951
  • Implement a 7-model bootstrap ensemble for recommendation confidence scoring and uncertainty quantification
  • Develop counterfactual risk-reduction ranking — simulating BP/weight/glucose interventions to rank recommendations by expected risk drop
  • Package 4 joblib models (raw XGB, calibrated, recommender base, bootstrap) with meta.json for reproducible deployment
  • Integrate recommendations into the CardioSense web app with per-label confidence scores and intervention explanations

Component 4 — Mental Health Monitoring

Main Objective: Create an AI-powered web application assisting doctors in mental health assessments via an interactive chatbot, with real-time explainable mental state evaluation against PHQ-9/GAD-7.

  • Fine-tune TinyLlama-1.1B (LlamaForCausalLM) using QLoRA (nf4 4-bit quantisation, LoRA rank=16, alpha=32) via HuggingFace PEFT
  • Curate a 38,249-sample training corpus from MentalChat16K, Empathetic Dialogues, MedQuAD (cardiac-filtered), and CounselChat datasets
  • Train using supervised fine-tuning (SFT) for 1 epoch (2,391 steps), achieving final training loss of 0.7983
  • Implement PHQ-9 and GAD-7 assessment workflows within the conversation flow for structured mental health screening
  • Build safety routing to detect self-harm and emergency patterns and escalate to clinical alerts
  • Deploy the trained model for inference with Firebase-backed session management per patient
